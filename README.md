# Trello Clone App 🧩

A simple Trello clone built with **NextJs**, **React**, **Prisma/SQlite**,  and **Tailwind CSS**. This app allows users to create boards, add cards, and drag & drop tasks — just like in Trello.

## 🔗 Live Demo
[View Demo](https://your-vercel-link.vercel.app) 

---

## 🛠️ Tech Stack

- **NextJs**
- **Prisma/SQlite**
- **React**
- **Tailwind CSS**
- **JavaScript**
- **Drag & Drop API**

---

## 🚀 Features

- Create multiple boards (columns)
- Add tasks/cards to each board
- Drag & drop cards between boards
- Responsive layout

## ⚙️ How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/lokki931/trello-clone-app.git
2. Navigate into the project directory:
   ```bash
   cd trello-clone-app
3. Install dependencies:
   ```bash
   npm install
4. Start the development server:
   ```bash
   npm run dev
