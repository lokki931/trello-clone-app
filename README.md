# Trello Clone App 🧩

A simple Trello clone built with **NextJs**, **React**, **Prisma/SQlite**,  and **Tailwind CSS**. This app allows users to create boards, add cards, and drag & drop tasks — just like in Trello.

## 🔗 Live Demo
[View Demo](https://your-vercel-link.vercel.app) 

---

## 🛠️ Tech Stack

- **NextJs**
- **Prisma/SQlite**
- **React**
- **Tailwind CSS**
- **JavaScript**
- **Drag & Drop API**

---

## 🚀 Features

- Create multiple boards (columns)
- Add tasks/cards to each board
- Drag & drop cards between boards
- Responsive layout
